# Dashboard output

`maintenance_operations_dashboard.xlsx` is an Excel workbook generated by `src/analyze.py`.

It includes:

- an executive summary with six KPI cards and recommended actions;
- category, hall, monthly, priority, team, and issue-type summary sheets;
- a cleaned-data sheet for inspection and filtering;
- a chart embedded in the executive summary.

The workbook is generated from synthetic data and is intended for portfolio demonstration.
