# Project brief

## Stakeholder

A fictional residence-life operations manager responsible for coordinating facilities, custodial, access, safety, and IT work across multiple residence halls.

## Problem

Requests arrive through several channels and may be difficult to prioritize consistently. Without a shared scorecard, managers may not know which issue types recur most often, where routing is slow, or whether high-priority work is being assigned within target time.

## Objective

Create a reproducible analysis that turns request-level data into a practical operating rhythm:

1. Clean and validate the request log.
2. Measure demand, speed, SLA performance, reopen rates, and satisfaction.
3. Identify recurring issue types and hall-level bottlenecks.
4. Recommend workflow changes that can be tested and measured.

## Success measures

- reliable request categorization;
- visible assignment and resolution KPIs;
- weekly review of open requests and SLA misses;
- fewer avoidable reopens;
- faster routing of emergency and high-priority requests.
